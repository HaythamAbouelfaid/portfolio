## Overview

SentinelOps is an **AI-assisted phishing investigation platform** designed to automate the early stages of suspicious webpage triage.

Phishing investigations typically require analysts to manually:
- open suspicious URLs in a controlled environment  
- capture screenshots and rendered HTML  
- extract indicators of compromise (IOCs)  
- identify phishing signals  
- document findings in a structured report  

To simulate and automate this workflow, I built SentinelOps as a **CLI-based cybersecurity tool** that combines browser automation, deterministic detection logic, and LLM-assisted analysis.

## System Architecture

<img src="/images/projects/project-01/10-sentinelops-architecture-workflow.png" alt="SentinelOps Architecture Workflow" />

The platform follows a modular pipeline:

- Analyst submits a suspicious URL  
- Browser automation collects rendered webpage artifacts  
- Indicators of compromise are extracted  
- Phishing detection features are derived  
- A deterministic risk score is calculated  
- LLM generates structured analysis  
- Reports are created and stored  
- Case data is persisted in SQLite  

This architecture ensures **explainability, modularity, and real-world applicability**.

## CLI Investigation Workflow

<img src="/images/projects/project-01/3-sentinelops-terminal-investigation-run.jpg" alt="SentinelOps Terminal Run" />

SentinelOps is operated through a command-line interface:

    python -m app.main --url "https://example.com" --notes "Investigation test"

During execution, the system:
- launches a browser session  
- captures HTML and screenshots  
- extracts IOCs  
- derives phishing indicators  
- calculates a risk score  
- generates structured reports

## Browser Evidence Collection

<img src="/images/projects/project-01/4-sentinelops-browser-artifact-wikipedia.jpg" alt="Browser Artifact Screenshot" />

Using **Playwright**, SentinelOps captures:

- Full-page screenshot  
- Rendered HTML snapshot  
- Visible text  
- Forms and input fields  
- Buttons and links  
- Page metadata  

This approach mirrors how a real analyst would inspect a suspicious webpage.

---

## IOC Extraction & Detection

SentinelOps extracts key indicators of compromise:

- URLs  
- Domains  
- Email addresses  
- IP addresses  
- Suspicious keywords  
- Brand mentions  

It then derives phishing-specific signals such as:

- login form presence  
- credential prompts  
- urgency language  
- payment-related language  
- impersonation indicators  
- suspicious domain patterns  

This deterministic logic improves **consistency and explainability** compared to AI-only approaches.

---

## Risk Scoring Engine

SentinelOps assigns a **deterministic phishing risk score (0–100)** based on detected indicators.

Severity levels include:

- Low  
- Medium  
- High  
- Critical  

Each score is backed by **explicit evidence**, allowing analysts to understand why a page was flagged.

---

## LLM-Assisted Threat Analysis

SentinelOps integrates **OpenRouter** to generate structured analysis based on collected evidence.

The LLM produces:

- Classification  
- Threat summary  
- Analyst rationale  
- Confidence level  
- Recommended actions  

The LLM is used as a **supporting analysis layer**, not as the primary detection engine.
